Learning Outcomes – BlueSky Intranet VNet Lab
Azure Networking
Designing segmented VNets  
Learned how to plan address spaces and subnet ranges to support multiple tiers and future growth.
Subnets and NSGs  
Practiced isolating workloads and applying NSG rules to control inbound and outbound traffic.
Secure Access
Deploying Azure Bastion  
Understood how Bastion provides secure RDP/SSH access without exposing ports directly to the internet.
Management vs. data plane separation  
Saw the value of keeping management resources in dedicated subnets.
Traffic Management
Configuring Load Balancer probes and rules  
Learned how health probes work and how load balancing rules route traffic to backend resources.
Single public entry point  
Reinforced the idea of fronting workloads with a load balancer instead of exposing individual VMs.
Compute and Application Hosting
Deploying and configuring a Linux VM  
Gained experience selecting images, sizing VMs, and configuring networking.
Installing and validating NGINX  
Practiced basic package management and service validation on Linux.
Observability and Diagnostics
Using a Storage Account for diagnostics/logs  
Learned how boot diagnostics and logs can be centralized for troubleshooting and monitoring.
Infrastructure as Code (IaC)
Writing Bicep templates  
Practiced defining Azure resources declaratively and parameterizing deployments.
Repeatable deployments  
Understood how IaC reduces configuration drift and speeds up environment recreation.
Documentation and Communication
Documenting cloud architecture  
Created architecture diagrams and written explanations that mirror real-world design documentation.
Portal flow documentation  
Captured step-by-step portal actions in a way that is clear, reproducible, and professional.
Overall Outcome
This lab strengthened my skills as an aspiring Azure Administrator by combining networking, security, compute, traffic management, diagnostics, and automation into a single, cohesive project that can be shared as a professional portfolio artifact.
