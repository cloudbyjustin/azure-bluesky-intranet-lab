🌤️ BlueSky Intranet VNet Lab
A beginner‑friendly Azure infrastructure project designed to demonstrate core AZ‑104 skills: virtual networking, compute, security, load balancing, storage, and secure access.
This project builds a mini corporate intranet with a secure VNet, subnets, NSGs, a Linux web server, a Load Balancer, and Azure Bastion for locked‑down administration.
